---
section: Behaviour changes in all modes
---

- BOOTy sends LLDP on the NICs that a netplan match block with
  `emit-lldp: true` selects (the legacy L2 netplan `all-en`, `all-eth`),
  also on a NIC that appears later, and in every network mode, like
  systemd-networkd; before, only the GoBGP underlay sent and took the
  block ID as an interface name (#756).
