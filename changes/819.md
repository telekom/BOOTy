---
section: Behaviour changes in all modes
---

- BOOTy no longer queries the NTP servers of the DHCP leases (option 42) by
  default, like the legacy ramdisk, which has no NTP client. Set
  `TIME_DHCP_NTP=true` (YAML `time.dhcpNTP`) to query them after
  `NTP_SERVERS` (#819).
- In DHCP mode every DNS lookup goes to all DNS servers at once and the
  first answer counts, like systemd-resolved queries the servers of every
  link (#819).
