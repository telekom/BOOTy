section: Behaviour changes in all modes
---

- `SECUREBOOT_SIGNING=per-host`: the allow list of the UKI `.cmdline`
  takes the kernel parameters of the T-CaaS compute profiles:
  `rcu_nocb_poll` and `nosoftlockup` as bare flags, `pci` with the options
  `realloc` and `assign-busses` only, and `systemd.unified_cgroup_hierarchy`
  and `audit` with `0` or `1` only. Other values of these names are refused
  also with `UKI_CMDLINE_POLICY=warn`. Values stay unquoted: send
  `isolcpus=2-15`, not `isolcpus='2-15'`, which is refused (#989).
